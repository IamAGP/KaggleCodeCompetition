What Kaggle is asking

Kaggle markets this as “Identify the model behind the text.” It is a Featured Code Competition with a $50,000 prize pool.

Featured is the competition category. Code means Kaggle reruns your submitted notebook on hidden passages. It does not mean “no AI” or “only simple algorithms.” Our entries use pretrained language models and trained adapters.

This is model attribution, not a human-versus-AI detector. All passages are AI-generated.

What does 0.622 mean?

The official metric is balanced accuracy: calculate the fraction identified correctly for each model, then average those 18 fractions. It is not simply “62.2% of all rows” unless the classes are equally represented.

A uniform random guess has expected accuracy about 5.56%. That is a mathematical reference, not a measured submission.

A local score is not a leaderboard score.

Recent local pilots usually evaluate 540 training passages held out by prompt. Most combine a candidate with a simpler reference than the full submitted ensemble. Kaggle’s test also uses unseen prompts.

V22 improved that local blend from 0.4741 to 0.5111, but its full-data submission, V23, scored 0.620—below V21’s 0.622. This mismatch is a central weakness in our experiment process.

0.700 is your target, not an established medal cutoff. Ranks and medal thresholds can change.

FROM PASSAGE TO PREDICTION

You don’t need to write code
to understand the system.

01

Learn from labeled examples

The data says “this passage came from gpt-6-astra,” or one of 17 other labels. A classifier learns statistical patterns that distinguish them. A short passage can share patterns with several models, so the answer is uncertain.

02

Hide whole prompts for a fairer rehearsal

If the same prompt appears in training and validation, familiar subject matter can help the detector. We keep entire prompt groups out of training because test prompts are new. A related-prompt split also keeps some similar prompts together.

120 fitting prompts · 2,159 rows30 held-out prompts · 540 rows

This is the common pilot split, not every experiment. Repeatedly inspecting one holdout can still make results optimistic.

03

Combine different kinds of evidence

The best submitted system starts with credited V16: text-pattern classification, Qwen language-model components and DeBERTa. V21 adds our contrastive representation at a fixed weight. The original balancing and topic-centering steps remain.

04

Train on all labeled rows and package the notebook

A promising method’s final fit can use all 2,699 labeled rows. Validation scores come from earlier held-out models—not from that full-data fit. We check model files, finite predictions, label order and output IDs before submission.

Three approaches, in everyday language

Text patterns

“Does this author use particular punctuation, word endings or phrases?” Fast classifiers learn those patterns.

Representations

“Can a language model turn this paragraph into useful features?” A small classifier reads them; fine-tuning changes what they capture.

Source likelihood

“Under which candidate author does this wording make most sense?” V30 compares token evidence under 18 source conditions.

What earns the next experiment?

First check whether the exact question has already been answered. Use predictions from models that did not train on the validation prompts. Compare against the actual incumbent where feasible; a weaker proxy must be labeled. Freeze the hypothesis and success criterion before looking at results, then confirm on other prompt groups.

Start with saved artifacts and cheap diagnostics. Expensive training comes after a discriminating test. A small local gain, especially on a repeatedly inspected holdout, does not establish a public-score gain.

My first priority: establish an honest comparison with the full baseline, then test source-matched external data. The provenance diagnostic justifies a question; it has not established the cause of our plateau.

Glossary

Classifier
A model that chooses from a fixed list—here, 18 source models.
Feature / embedding
A numerical description of a passage, from punctuation counts to neural representations.
Frozen model
A pretrained model whose weights we do not change. We can still train a classifier on its outputs.
Fine-tuning / LoRA
Adapting a pretrained model. LoRA trains small added matrices instead of changing every parameter.
Contrastive learning / SupCon
Make representations with the same label closer and different labels more separated. We pair different prompts from the same author.
Cross-entropy / CE
A training loss that rewards higher probability for the correct label.
Ensemble / blend
Several models combining evidence into one decision.
Fold / OOF / CV
A fold is a held-out group. Out-of-fold predictions come from models not trained on those rows. Cross-validation repeats this across folds.
Leakage
Validation information reaching training or selection in a way that makes evaluation overoptimistic.
Bootstrap interval
Uncertainty estimated by resampling—here, whole prompts. It does not undo repeated-holdout selection bias.
Promotion gate
A threshold fixed before an experiment to decide whether it merits the next stage. A local pass does not guarantee a leaderboard gain.
Sinkhorn balancing
A procedure that adjusts predictions toward a chosen overall class distribution. The credited baseline uses it; class balance is an assumption.
Public versus private score
The public leaderboard uses one part of the hidden test. Final ranking can use another private portion; public gains may not transfer.
